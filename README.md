# Экзамен по задачнику Абрамяна

Экзаменационное приложение на Python/FastAPI по первой части задачника
М. Э. Абрамяна «1000 задач по программированию».

Студент получает 5 случайных задач (по одной из блоков `Integer`, `If`,
`For`, `Proc`, `Series`), 25 минут и по 10 попыток запуска кода на каждую
задачу. Проверка — по скрытым автотестам. Смена вкладки или закрытие
браузера во время экзамена приводят к дисквалификации.

## Разработка

```bash
uv sync --extra dev
uv run uvicorn app.main:app --reload
uv run pytest
```

## Сборка для Linux

```bash
bash scripts/build_linux.sh
```

Результат — один исполняемый файл `dist/abramyan-exam`, не требующий
Python и прав администратора на целевой машине.
