# Экзамен по задачнику Абрамяна

Экзаменационное приложение на Python/FastAPI по первой части задачника
М. Э. Абрамяна «1000 задач по программированию».

Студент получает **5 случайных задач** — по одной из блоков `Integer`, `If`,
`For`, `Proc`, `Series` (первые 20 задач каждого блока). На весь экзамен
даётся **30 минут**, на каждую задачу — **10 попыток запуска** кода.
Проверка автоматическая, по скрытым тестам: студент видит только количество
пройденных тестов. Смена вкладки, закрытие браузера или потеря связи с
страницей во время экзамена означают мгновенную дисквалификацию.

## Быстрый старт (разработка)

Нужен Python 3.12+ и [uv](https://docs.astral.sh/uv/).

```bash
uv sync --extra dev
uv run python -m app
```

Приложение откроется на <http://127.0.0.1:8000/>. В консоль выводятся адрес
панели преподавателя и одноразовый токен. Токен также хранится в
`exam-data/.teacher-token`.

```bash
uv run pytest                 # все тесты
uv run pytest --cov=app       # покрытие
```

## Сборка одного файла для Linux

Сборка выполняется на Linux (нативно или в WSL Ubuntu). Целевой машине не
нужны Python, pip или права администратора.

```bash
bash scripts/build_linux.sh
```

Результат — `dist/abramyan-exam` (один ELF-файл); скрипт также кладёт копию
в `release/abramyan-exam-linux-x86_64` и пишет `release/SHA256SUMS`. Скрипт
собирает два бинарника: основное приложение и встроенный sandbox-исполнитель
кода, который упаковывается внутрь основного файла. Итоговый файл можно
копировать на машину с x86_64 Linux (glibc 2.35+) и запускать:

```bash
chmod +x abramyan-exam
./abramyan-exam
```

Проверка собранного файла без открытия браузера:

```bash
bash scripts/smoke_linux.sh       # health, стартовая страница, панель учителя
bash scripts/smoke_artifact.sh    # полный цикл: код, 8 тестов, таймаут, бан
```

### Переменные окружения

| Переменная | По умолчанию | Значение |
|---|---|---|
| `EXAM_HOST` | `127.0.0.1` | Адрес прослушивания. `0.0.0.0` — для класса |
| `EXAM_PORT` | `8000` | Порт |
| `EXAM_MINUTES` | `30` | Длительность экзамена |
| `EXAM_ATTEMPTS` | `10` | Попыток на каждую задачу |
| `EXAM_DATA_DIR` | рядом с бинарником | Каталог SQLite-базы и токена |
| `EXAM_TEACHER_TOKEN` | генерируется | Токен панели преподавателя |
| `EXAM_OPEN_BROWSER` | `1` для бинарника | Открывать браузер при старте |
| `EXAM_RUN_TIMEOUT` | `2` | Секунд на один тест |
| `EXAM_RUN_BUDGET` | `8` | Секунд на весь запуск кода |
| `EXAM_HEARTBEAT_GRACE` | `35` | Секунд без heartbeat до бана |

Пример для компьютерного класса:

```bash
EXAM_HOST=0.0.0.0 EXAM_PORT=8000 ./abramyan-exam
```

Студенты открывают `http://<ip-учителя>:8000/`. Панель преподавателя —
`/teacher?token=...`, выгрузка CSV — `/teacher/export.csv?token=...`.

> Приложение не содержит встроенной аутентификации студентов: оно рассчитано
> на доверенную локальную сеть или запуск на компьютере студента. Токен
> преподавателя не показывается студентам.

Чтобы очистить результаты перед новой группой, остановите приложение и
удалите каталог `exam-data` (он создаётся рядом с бинарником или в
`~/.local/share/abramyan-exam`).

## Как устроен экзамен

1. Студент вводит имя и подтверждает правила античита.
2. Сервер выбирает случайную задачу из каждого блока и фиксирует дедлайн
   на сервере (30 минут).
3. Экзамен открывается только после входа в полноэкранный режим
   (Fullscreen API), иначе задания и редактор заблокированы.
4. Код пишется в браузере на Python, запускается кнопкой или `Ctrl+Enter`.
5. Каждый запуск расходует одну попытку. Проверяются все скрытые тесты
   (обычно 8 на задачу); в ответе видно только `пройдено N из M`.
6. Задача считается решённой, если все тесты прошли. Повторный запуск решённой
   задачи запрещён.
7. Экзамен завершается кнопкой «Завершить» или автоматически по таймеру.
8. Преподаватель видит таблицу всех попыток и может выгрузить CSV.

### Редактор и обратная связь

Редактор — локальный CodeMirror 5.65.18 (MIT, без CDN; файлы и лицензия в
`app/static/vendor/codemirror/`): подсветка Python, номера строк, автозакрытие
и подсветка парных скобок, активная строка, поиск `Ctrl+F`, комментарии
`Ctrl+/`, автодополнение `Ctrl+Space`, отступы `Tab` и запуск `Ctrl+Enter`.

При неудачном запуске показываются номера проваленных тестов и разбор
**только первого** проваленного теста: входные данные, ожидаемый и
фактический вывод. Остальные тесты остаются скрытыми. Для ошибок выполнения
показывается короткое сообщение (`SyntaxError`, `ZeroDivisionError` и т. п.)
без полного traceback.

После завершения экзамена на странице результата можно раскрыть финальный
код по каждой задаче — тот, который был сохранён на момент сдачи.

### Античит

- Экзамен заблокирован оверлеем, пока студент не войдёт в полноэкранный
  режим. Выход из него, в том числе по `Esc`, → немедленный бан.
- В полноэкранном режиме вызывается Keyboard Lock API (где браузер его
  поддерживает), а браузерные сочетания (`F5`, `F12`, `Ctrl+W`, `Ctrl+R`,
  `Ctrl+Shift+I` и т. п.) перехватываются на странице.
- `Alt+Tab` и любая потеря фокуса окна → бан. Это работает и там, где
  Keyboard Lock недоступен.
- `visibilitychange` при уходе со вкладки → немедленный бан.
- `pagehide` при закрытии/уходе со страницы → бан через `sendBeacon`.
- Heartbeat каждые 5 секунд; если браузер пропал более чем на 35 секунд,
  серверный sweep переводит попытку в `banned`.
- После бана страница результатов недоступна, дальнейшие запуски кода
  отклоняются.

Браузер не может перехватить часть системных сочетаний (`Ctrl+Alt+Del`,
меню ОС и т. п.) — это ограничение веб-платформы. Для режима киоска на
экзаменационном компьютере дополнительно настройте блокировку ОС.

Сервер — источник истины: таймер, попытки и статус проверяются на сервере,
клиентские значения не используются для начисления баллов.

## Задачи и автотесты

Все 100 задач (по 20 из каждого блока) находятся в
`app/content/tasks.json`. У каждой задачи есть:

- полная формулировка, формат ввода/вывода, пример;
- 8 скрытых тестов с эталонными ответами;
- стабильный ID (`integer-01`, `if-02`, …).

Генератор тестов и эталонные решения — `app/content/build_tests.py`. В
поставляемом бинарнике эталонных решений нет: только входы и ожидаемые
выходы. Тесты проверяют, что эталонные решения воспроизводят сохранённые
ответы, что у каждой задачи не меньше 6 тестов и что все 20 задач каждого
блока на месте.

Сравнение ответов токенное и допускает разное форматирование чисел:
`1.0` и `1`, лишние пробелы и переводы строк не ломают проверку; для
вещественных чисел допуск `1e-6`. Лишние слова и отладочный вывод считаются
ошибкой.

## Исполнитель кода

Студенческий код запускается отдельным процессом `exam-runner`:

- запрещены опасные builtins (`open`, `exec`, `eval`, `compile`, `globals`, …);
- разрешён только импорт `math`;
- запрещены dunder-атрибуты и dunder-имена;
- лимиты `RLIMIT_CPU`, `RLIMIT_AS`, `RLIMIT_FSIZE`, `RLIMIT_NPROC`;
- жёсткий таймаут на тест и общий бюджет запуска;
- ограничение вывода (64 КБ);
- минимальное окружение и временный рабочий каталог.

Это практическая защита для экзамена, а не полноценная контейнерная
изоляция. Для недоверенных пользователей и публичного доступа запускайте
приложение в контейнере/ВМ с отдельным пользователем.

## Структура проекта

```
app/
  main.py            FastAPI-роуты, панель преподавателя
  db.py              SQLite: сессии, попытки, события
  exam.py            выбор билета и view-модели
  executor.py        запуск тестов через sandbox
  sandbox_runner.py  отдельный исполнитель студенческого кода
  grading.py         сравнение вывода
  tasks.py           загрузка каталога задач
  content/           задачи, тесты, генератор
  templates/         Jinja-шаблоны
  static/            CSS и JS экзамена
tests/               pytest: API, БД, sandbox, содержание задач
scripts/             сборка и smoke-check Linux-бинарника
.opencode/           ECC skills/agents, см. .opencode/ECC-NOTICE.md
```
